Ariadne is a containerized software engineering workflow platform. It coordinates specialized agents through explicit task handoffs, verification and review gates, with durable workflow state stored in PostgreSQL. The platform is designed to make engineering execution traceable and recoverable rather than relying on conversational state alone.
