[file-meta-mcp](https://github.com/ipolyzos/file-meta-mcp) is a read-only [Model Context Protocol](https://modelcontextprotocol.io/) server written in Go. It exposes file stat, disk usage, filesystem usage, and SHA-256 hashing over stdio transport — designed for use with Cursor and similar MCP-compatible AI clients.
