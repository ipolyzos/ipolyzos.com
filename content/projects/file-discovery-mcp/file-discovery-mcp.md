[file-discovery-mcp](https://github.com/ipolyzos/file-discovery-mcp) is a [Model Context Protocol](https://modelcontextprotocol.io/) stdio server written in Go. It wraps find(1) in a safe, structured, read-only interface — enabling AI agents to traverse and discover filesystem contents within allowlisted roots.
