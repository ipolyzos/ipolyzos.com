[json-query-mcp](https://github.com/ipolyzos/json-query-mcp) is a [Model Context Protocol](https://modelcontextprotocol.io/) stdio server written in Go. It wraps jq in a safe, structured, read-only interface — enabling AI agents to query, filter, and transform JSON data without direct shell access.
