[log-mcp](https://github.com/ipolyzos/log-mcp) is a [Model Context Protocol](https://modelcontextprotocol.io/) server written in Go. It provides read-only log analysis and structured inspection for Unix-flavoured systems — enabling AI agents to query, filter, and reason over log files safely.
