Hephaestus is a Claude Code plugin for disciplined, end-to-end software delivery: plan, build test-first, review independently, and claim "done" only with evidence. It bundles skills for planning, commits, pull requests, releases and incident work, plus practice guides for languages from Go and Java to Zig and Clojure; subagents that draft changes and others that review them from separate, read-only perspectives (code, security, tests, infrastructure, SRE); and guard hooks that block bypassed checks, commits to `main`, leaked secrets and AI attribution in git history. It is built for a single developer first and is in active use.
